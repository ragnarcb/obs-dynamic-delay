## English

**[Download Dynamic-Delay-Setup.exe](https://github.com/ragnarcb/obs-dynamic-delay/releases/latest/download/Dynamic-Delay-Setup.exe)** · English, Portuguese and Spanish in one file

**Fixed: the delay seemed to turn on by itself when going live.** If a stream ended with the delay on, the next one (with OBS still open) started with it on too. Now each stream you end in OBS resets it: the next one starts as **Start every stream with the delay on** says. You can still switch the delay on before going live, and if your connection drops, the delay stays as it was so nothing airs early.

**Fixed: Configure OBS, Restore OBS and the Twitch/Kick bitrate rules did not work from OBS** ("Could not locate the OBS profile" when going live). They work again.
