## English

**[Download Dynamic-Delay-Setup.exe](https://github.com/ragnarcb/obs-dynamic-delay/releases/latest/download/Dynamic-Delay-Setup.exe)** · English, Portuguese and Spanish in one file

**Fixed: Kick would not start in multistream with the Twitch VOD track on.** The relay was sending the VOD track to every destination, and Kick rejects it, so Kick kept reconnecting. Now the VOD track goes only to Twitch, and Kick, YouTube and the others get the normal stream audio. Install over the current version, nothing else to change.

**Safer uninstall.** If OBS is open or putting its settings back fails, the uninstall stops before deleting anything, so you can close OBS and try again. Each OBS profile gets its own settings back, and settings you changed by hand later are kept. Thanks to @gabrielvenerusso.
