## English

**[Download Dynamic-Delay-Setup.exe](https://github.com/ragnarcb/obs-dynamic-delay/releases/latest/download/Dynamic-Delay-Setup.exe)** · English and Portuguese in one file

**A real Windows installer.** One Setup for both languages: pick the language, then the wizard installs for your Windows user (no administrator), checks that OBS is closed, sets up OBS and lists what it did, with "Open OBS now" at the end. Dynamic Delay now shows up in Windows Settings > Apps, uninstalls cleanly (your original stream settings come back) and updates over the old version.

**New look.** A new logo and professional icons (Phosphor) in the panel, the phone deck and the Stream Deck plugin. The program has an icon, publisher and version information.

**Windows SmartScreen:** while the program is new and not yet code-signed, Windows may say "Windows protected your PC". Click **More info > Run anyway**. You can check the download against `SHA256SUMS.txt`.

If you used an older version: run the new Setup, it installs over it and keeps your settings and keys.

**Um instalador de verdade para Windows.** Um único instalador para os dois idiomas: você escolhe o idioma e o assistente instala para o seu usuário do Windows (sem administrador), confere se o OBS está fechado, configura o OBS e mostra o que fez, com "Abrir o OBS agora" no final. **SmartScreen do Windows:** enquanto o programa é novo e ainda não tem assinatura digital, o Windows pode dizer "O Windows protegeu o computador". Clique em **Mais informações > Executar assim mesmo**. Dá para conferir o download com o `SHA256SUMS.txt`.

Se você usava uma versão antiga: rode o instalador novo, ele instala por cima e mantém sua configuração e suas chaves.
